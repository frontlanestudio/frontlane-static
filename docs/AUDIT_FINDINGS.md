# Frontlane Static Quality Audit & Real-World Validation

This audit was generated by running automated structural and asset verification against offline clones of real-world law firm websites downloaded from the CallJacob platform.

## Summary of Findings

| Metric | Value |
|--------|-------|
| Clones Audited | 88 |
| Perfect Clones | 10 |
| Broken Local Asset References | 25250 |
| Unrewritten Host URLs | 1131262 |
| Subdomain Assets Dropped | 930687 |
| Inline `style="url()"` Dropped | 7706 |
| Empty Clones | 11 |

## Discovered Issues & Action Plan

1. **[BUG-01: Subdomain Asset Rewriting](issues/BUG-01-subdomain-asset-rewriting.md)**
   Assets on `www.` or `cdn.` are downloaded, but link rewriting requires strict equality on `host_str()`, leaving references absolute.
2. **[BUG-02: Inline & <style> Tag url() Rewriting](issues/BUG-02-inline-and-tag-style-url-rewriting.md)**
   Background images and fonts in inline styles (`style="background-image: url(...)"`) or `<style>` tags are not discovered by the crawler or rewritten.
3. **[BUG-03: Protocol-Relative URLs](issues/BUG-03-protocol-relative-urls.md)**
   Protocol-relative URLs need normalized handling across `srcset` and CSS imports.
4. **[FEAT-01: Headless Scroll & Lazy-Load Trigger](issues/FEAT-01-headless-scroll-and-lazy-load-trigger.md)**
   Headless mode should optionally scroll to page bottom to trigger dynamic lazy loading.
5. **[FEAT-02: Sitemap Probe Timeout & Fallback](issues/FEAT-02-sitemap-probe-timeout-and-fallback.md)**
   Add sitemap probing timeout so large XML indexes don't stall site crawling.
